title: "v0.11 - Game Pane"
weight: 110
---

Adds a `game` pane type for small 2D games, Snake first, so waiting on an agent can be a break instead of a context switch. The chain is deliberately small and self-contained: built-in games only, no files, network or third-party code (a native pane SDK stays out of scope per the architecture boundary), and no part of the control surface or the daemon depends on it. It builds on the v0.8.0 theme tokens and palette and the v0.9.5 notification signals.
