Launch is deferred: `gPTY` stays below 1.0.0 until either the project gains a growing, active userbase or the 0.x feature-set is exhausted - code signing and broad distribution are only worth pursuing once one of those is true.

## v1.0.0 - Public Launch

| Done | Area | Item |
|:---:|:---:|---|
| ⬜ | BUILD | **Distribution** - Homebrew tap, winget, and the AUR package's release-time update (promoted from Future: launch blockers), on top of the GitHub release bundles. `install.sh` moved to v0.8.0 (owner decision 2026-10-25); what is left here is the package managers that put `gpty` on `PATH` with no terminal step, and both depend on the CLI finding a GUI that was installed somewhere else (also v0.8.0). |
| ⬜ | BUILD | **Code signing** - macOS notarization + Windows Authenticode (promoted from Future: SmartScreen/Gatekeeper warnings are launch-killers). **Decided 2026-10-25:** Windows goes through the SignPath Foundation (free for qualifying open source) rather than a paid certificate; the application is submitted and on hold until the project has published articles/posts it can point at as evidence of use, so Windows signing waits on that. macOS notarization is held to the same point, and it is not needed for the installer: a curl-downloaded build carries no `com.apple.quarantine` xattr, so `install.sh` runs an unsigned build while a browser download of the same build is refused on macOS 15+. Do not buy an EV certificate in the meantime: since 2024 EV no longer bypasses SmartScreen (Microsoft's own guidance). |
| ⬜ | DOCS | **Docs** - agent guide, plugin authoring guide, socket API reference (from the existing schema generator), 60-second quick start. |
| ⬜ | PROJECT | **Community infrastructure** - plugin registry live, examples repo, community channel. |
| ⬜ | PROJECT | **Launch criteria** - first-class agent adapters, example plugins, the reference workflow demo (agent runs tests in a pane while the user watches in the GUI), and a working headless reattach story - all verified before the public launch post. |
