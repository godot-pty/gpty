Three small releases that took gPTY beyond the GUI and hardened it. v0.3.0 added the `gpty` CLI, the MCP server, daemon mode and the IPC bridge; v0.3.1 made gPTY stable on Windows (named-pipe IPC) and put a release-quality CI gate in place; v0.3.2 was the first security and test-coverage pass. Everything in this chain shipped.
