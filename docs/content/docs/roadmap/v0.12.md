## v0.12.1 - Markdown Authoring

The note editor's authoring surface. The rows are ordered the way the queue is: the correctness item first,
the toolbar next as the release's headline, then the surface's navigation, then the authoring and renderer
depth that follow from it, then polish.

The implementation spec for these rows - the exact APIs, literals, chords and test cases the research
settled - is a local working note at `TEMP/markdown-authoring-plan.md` in the repository root. It is
gitignored (the `TEMP*` entry in `.gitignore`) and never shipped; it exists so a row can be picked up
without re-running the research.
