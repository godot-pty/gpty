Panes that watch an agent rather than a shell: the Inspector and Reasoning panes, the OMP event channel and an OMP workspace profile, plus stable pane attachment ids and safe Markdown rendering. Everything in this chain shipped.

## v0.4.0 - Inspector & Reasoning

| Done | Area | Item |
|:---:|:---:|---|
| ✅ | AGENT | **Inspector pane** - private, tool-free, iterative OMP Q&A via a session-owned `GptyAi` (`session_open` / `session_prompt` / `session_poll` / `session_cancel` / `session_close`); does not attach to a terminal-hosted OMP TUI; pane `backend` setting (default `omp`) |
| ✅ | AGENT | **Reasoning pane** - passive projection of documented OMP reasoning from one terminal, selected by `source_attachment_id`; never starts jobs or accepts concept captures |
| ✅ | AGENT | **OMP event channel** - second local socket (`gpty-events.sock`) accepting only `ompEvent`, authenticated with a per-PTY capability injected at spawn; shipped `@gpty/omp-events` extension dormant unless all four `GPTY_EVENT_*` vars are present |
| ✅ | AGENT | **"OMP Workspace" profile** - shipped built-in (Terminal + Inspector + Reasoning), never written to the user store and not deletable |
| ✅ | CORE | **Stable pane `attachment_id`** - persisted companion links across save/restore (not ephemeral labels like `T1`) |
| ✅ | WIKI | **Safe Markdown rendering** - CommonMark/GFM converted to sanitized Godot BBCode in Rust; render-debounced streams; code-viewer rendered/source toggle |
