title: "v0.5 - ADE Foundation"
weight: 50
---

This chain turned gPTY from a multi-terminal emulator into a graphical PTY foundation with a public, agent-facing API. v0.5.0 set the architecture boundary and the pane read/status/run/wait API; v0.5.1 added SQLite-backed persistence; v0.5.2 agent state and adapters; v0.5.3 terminal performance, mouse reporting and Workspace Trust; v0.5.4 the visual concept graph and a large hardening pass; v0.5.5 the plugin ecosystem; and v0.5.6 CLI semantics and single-instance behaviour. Everything in this chain shipped.
