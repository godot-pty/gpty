Seven releases that make the interface the reason to use gPTY. v0.8.0 re-baselines the October 2026 audit, commits the capture harness, and lays down the shared theme, type scale, colour tokens, light theme and accessibility baseline. v0.8.1 is pane chrome, palette and discoverability. v0.8.2 is the pane-interaction and responsiveness fixes that came out of daily use - explicit close affordances, a saved empty workspace, the active-pane and close-fallback repairs, the clamped dialogs, the flood cadence and the workspace-switch cost. v0.8.3 is small windows, sidebar space and the remaining pane responsiveness work. v0.8.4 is pane configuration, launch commands and profile identity, plus the last defects pulled forward from the visual release - a spawn-directory mismatch, a short-scheme palette reset and content-sized cards - and the capture-harness compile fix that makes its evidence honest. v0.8.5 is the repair patch the v0.8.4 tag forced - a tag ruleset that forbade creating tags at all, and a macOS archive whose alias fix never reached the transport - and it carries release-pipeline work only. v0.8.6 is the Godot-native visual layer - shaders, pane transitions, reactive environments and a physical 3D vault graph - and the release capture. v0.8.7 is the finish pass those leave open: one switch behind every animation, a scheme-owned backdrop, elevation for floating surfaces, and a focus change the eye can follow. Every row in this chain is UI/UX work or the capture tooling that records it; build, security, MCP, distribution and promotion work lives in v0.9.

## v0.8.5 - Release Repair

The patch v0.8.4 made necessary. Its tag could not be pushed at all: the `tag` ruleset carried a `creation` rule with no bypass actors, and `scripts/check-github-settings` asserted the same wrong rule set, so the gate reported OK while the policy it guards made every release impossible. Publishing then shipped a macOS archive whose FFmpeg alias fix never reached the transport. Both are release-pipeline work, the only kind of change this release carries.

## v0.8.7 - Depth, Backdrop & Motion

The finish pass the visual-identity release leaves open: motion gets one switch behind it, the terminal body gets a scheme-owned backdrop, floating surfaces get depth, a focus change becomes findable, and the vault graph gains depth travel and a theme table of its own. The study book that seeded these rows (`sparks-and-sprites`: prose CC-BY 4.0, code MIT) is a catalogue of presentation mechanics, and only its interface half is adopted here - character animation, procedural generation, flipbooks, input verbs and cursor trails are deliberately out of scope, because gPTY is a reading and orchestration surface, not a game. Motion is allowed where it announces a change - the Getting Started guide, a pane's first paint, a created sidebar row, the tab just opened - and never on text being read: the terminal grid, a streaming Reasoning turn, a note body or source code stay still.
