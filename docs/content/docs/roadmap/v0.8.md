Six releases that make the interface the reason to use gPTY. v0.8.0 re-baselines the October 2026 audit, commits the capture harness, and lays down the shared theme, type scale, colour tokens, light theme and accessibility baseline. v0.8.1 is pane chrome, palette and discoverability. v0.8.2 is the pane-interaction and responsiveness fixes that came out of daily use - explicit close affordances, a saved empty workspace, the active-pane and close-fallback repairs, the clamped dialogs, the flood cadence and the workspace-switch cost. v0.8.3 is small windows, sidebar space and the remaining pane responsiveness work. v0.8.4 is pane configuration, launch commands and profile identity. v0.8.5 is the Godot-native visual layer - shaders, pane transitions, reactive environments and a physical 3D vault graph - and the release capture. Every row in this chain is UI/UX work or the capture tooling that records it; build, security, MCP, distribution and promotion work lives in v0.9.
